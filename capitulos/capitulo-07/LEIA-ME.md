# Capítulo 7 — Quando há muitos dados

**Parte:** Parte III — Trabalhando com Muitos Dados

## Objetivo geral

Agrupar informações relacionadas, percorrer uma coleção e produzir indicadores a partir dos dados, inclusive em casos limite.

Encaminhamento registrado no sumário preliminar: Analisar os resultados de uma turma ou outro conjunto significativo de informações.

## Natureza prevista do material complementar

Exemplos com coleções e, quando o capítulo for desenvolvido, arquivos de dados próprios. A biblioteca padrão é suficiente; uma biblioteca externa depende de justificativa pedagógica.

As pastas `exemplos/`, `exercicios/`, `solucoes/`, `testes/`, `dados/` e `diagramas/` serão criadas somente quando houver material correspondente.
